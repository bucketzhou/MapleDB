# 同版本 Bloom 开关对照

启用配置为 10 bits/key。倍率 = 启用中位吞吐量 / 关闭中位吞吐量，变化百分比同样基于吞吐量。
每个 CSV 中两引擎的配对验证和完整逐轮范围见对应 summary。
